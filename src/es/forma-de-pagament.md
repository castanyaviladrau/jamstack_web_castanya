Esta pagina resume los metodos de pago disponibles en la tienda online de Castanya de Viladrau y como se gestiona el cobro durante el proceso de compra.

## Moneda e importe final

Todos los precios de la web se expresan en **euros (€)**. El importe final del pedido se muestra antes de completar el pago y puede incluir, si procede, los gastos de envio u otros conceptos informados durante el proceso de compra.

## Metodos de pago disponibles

Actualmente, la tienda ofrece el siguiente metodo de pago:

- **Tarjeta bancaria**

Este pago se tramita a traves de un **TPV seguro de Redsys**.

## Pago con tarjeta

Cuando la persona clienta elige el pago con tarjeta, el cobro se realiza a traves de una pasarela segura. Castanya de Viladrau no almacena ni tiene acceso completo a los datos bancarios introducidos durante la operacion.

## Confirmacion del pedido

Una vez tramitado correctamente el pago, el pedido puede quedar registrado en el sistema y la persona clienta recibe la confirmacion correspondiente, ya sea en pantalla, por correo electronico o por ambos canales.

## Incidencias de pago

Si se produce algun error durante el proceso de cobro, el pedido puede quedar pendiente o no llegar a confirmarse. En este caso, se recomienda:

- revisar si se ha recibido algun mensaje de confirmacion
- comprobar si el cobro se ha completado realmente
- contactar con **info@castanyadeviladrau.cat** antes de repetir el pago

## Seguridad

Castanya de Viladrau utiliza canales y proveedores de pago orientados a proteger la confidencialidad de las operaciones. Aun asi, la persona usuaria debe verificar que los datos introducidos sean correctos antes de confirmar la transaccion.
